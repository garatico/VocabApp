# dutch.txt — hand-curated seed vocabulary for German.
#
# Read by:  python scripts/data/pipeline.py seed --langs nld
#
# Why this file exists
# -------------------
# Every other language was bootstrapped by `mine`, which needs spaCy plus a
# network connection for Wiktionary/Google Translate glosses. German had
# neither available when it was added, and mining from a cold gloss cache is
# a slow first run regardless. This is the manual alternative: a curated core
# vocabulary that gives the language something usable on day one. `mine` then
# builds on top of it and skips everything already here.
#
# Format
# ------
#   word|pos|gender|gloss;gloss;gloss
#
#   word    as it is actually written — Dutch nouns are lowercase, unlike German
#   pos     noun | verb | adjective | adverb
#   gender  common | neuter        (nouns only — de-words vs het-words)
#   glosses English, most common sense first; the first becomes `translation`
#
# Blank lines and lines starting with # are ignored.
#
# What the pipeline adds
# ----------------------
# rank, band, difficulty and corpus_frequency are NOT written here. The seed
# step reads them from data/opensubtitles_freq_corpora/nl/nl_50k.txt, so the
# frequency data is real and this file cannot drift from it. Entries are
# ordered by actual corpus frequency, so "Top 100" in the app means the 100
# commonest of these.
#
# Part of speech and noun capitalisation are checked against HanTa when it is
# installed (pip install HanTa) and disagreements are reported. German
# homographs are separated by case — Frage/frage, Liebe/liebe, Arm/arm — so
# the check tags nouns in their capitalised form.
# NOTE: HanTa is a German tagger, so the seed step's POS cross-check is
# skipped for Dutch. Mine with the nl_core_news_sm spaCy model to verify.
#
