Data Structure & Fields

📋 CSV Seed File Format

Seed CSV files are stored in backend/data/sources/ and contain 17 columns:

Column Purpose Example
rank Word frequency ranking (1-1000) 1
word Spanish word (required) hablar
display How word appears in UI (usually English) to speak
glosses Translations (pipe-separated: gloss1|gloss2) speak|talk|say
pos Part of speech (noun, verb, adjective, etc.) verb
difficulty 1-5 scale (1=beginner, 5=advanced) 1
tags Metadata tags (pipe-separated) common|frequent
notes Usage notes, common mistakes, context Regular verb
examples Usage examples (pipe-separated) Hablo español|She talks a lot
synonyms Similar words (pipe-separated) conversar|charlar|dialogar
antonyms Opposite words (pipe-separated) silencio|callar
ipa International Phonetic Alphabet [aˈβlaɾ]
frequency_band CEFR level (A1, A2, B1, B2, C1, C2) A1
gender Grammatical gender (m/f for nouns) m or f
plural Plural form for nouns libros
infinitive Base form for conjugated verbs hablar
reflexive Whether verb is reflexive (true/false) true

✏️ How to Edit Data

  1. Edit in Admin Panel: Search word, fill form fields, click Save. Changes write to JSON immediately.
  2. Edit CSV + Regenerate: Open CSV file, edit rows, save file, click "Generate [Language]" button.
  3. Export to CSV: Click export buttons to download current JSON as CSV for backup or bulk editing.

💡 Tips

  • Array fields: glosses, tags, examples, synonyms, antonyms use pipe separator: value1|value2|value3
  • Quick Wins: Fills missing examples, synonyms, IPA, registers automatically (free enrichment)
  • Search: Find words by Spanish word, display text, or English glosses
  • Statistics: View coverage metrics (% of words with examples, synonyms, etc.)
  • Difficulty: 1=beginner, 2=elementary, 3=intermediate, 4=upper-intermediate, 5=advanced
