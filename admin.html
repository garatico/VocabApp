Database Administration

Clear All Caches

Forces the server to re-read all languages from SQLite on the next request.

Reload Database

Closes and reopens vocabulary.db from disk — use this after replacing the file itself (a pipeline sync, restoring a backup), not just after editing rows. The server also does this on its own the moment it notices the file changed, so this button is mainly for an immediate confirmation rather than a strict requirement.

Clear Language Cache

Clear the in-memory cache for one language only.

Export to CSV

Download the current SQLite data for a language as a CSV file.

Data Structure & Help

📋 Editable Fields

Field Purpose Format

pos Part of speech noun, verb, adjective…

difficulty Difficulty tier, derived from frequency rank 1 (most common) – 5 (rarest)

reflexive Whether the verb is reflexive Checkbox

examples Usage example sentences — one per line Plain text
notes Usage notes, common mistakes Plain text

🗄️ Database Notes

  • Vocabulary is stored in SQLite (data/vocabulary.db).
  • Glosses and examples are stored in separate tables and fully replaced on each save.
  • Domains are stored as a JSON array. The editor sets one domain at a time.
  • After saving, the server cache for that language is cleared automatically.
  • Synonyms (word_relations table) are not yet editable in this panel.

💡 Tips

  • Search matches on word key, translation, and any gloss.
  • Filters (POS, Band, Domain) narrow the word list and combine with search.
  • Glosses: put each translation on its own line.
  • Examples: put each sentence on its own line.
  • Syllables: use hyphens — e.g. ha-blar, ca-sa.
  • Use Export CSV in DB Admin for bulk edits in a spreadsheet.
